# Testando BDD

Material de estudo de Banco de Dados (2º bimestre).

- `Resumo_2Bim_Explicado.txt`: INSERT, SELECT, ligação de tabelas no WHERE, JOINs, GROUP BY, UNION e VIEW, com as listas de exercícios resolvidas e comentadas. Roda inteiro num PostgreSQL vazio.
- Parte 6 tem a consulta da apresentação **cidade | tipo | média** (UNION de vendas e compras com `AVG`), explicada passo a passo e com o resultado esperado.
- Parte 8 é um tutorial do **DBeaver**: instalar, conectar no PostgreSQL, rodar o script, ver as tabelas e resolver os erros mais comuns.
